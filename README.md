## Вариант 1: Идеально для GitHub Pages / Render (мгновенная загрузка по ссылке)
Загрузи в новый репозиторий на GitHub эти 3 файла в корень:
-  (легкий код страницы — 55 КБ)
-  (голос + басовый саунд-дизайн)
-  (фоновая музыка Stage Spotlight на 30% громкости)

Затем в репозитории GitHub открой:
**Settings → Pages → Build and deployment → Branch:  → Save**.
